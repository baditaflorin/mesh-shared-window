# 0003 — Grid topology with auto-sized columns

## Context

`mesh-shared-window` shows _all_ peers' frames in a grid (contrast with `mesh-mirror`'s ring chain, where each phone sees exactly one peer). The grid has to adapt to the room size.

## Decision

`gridCols(n)`:

- `n ≤ 1` → 1 column (just your own preview if you're alone).
- `2 ≤ n ≤ 4` → 2 columns (1–2 rows).
- `5 ≤ n ≤ 9` → 3 columns.
- `n ≥ 10` → 4 columns.

Tiles fill cells with `object-fit: cover` so each frame fills its slot regardless of aspect ratio.

## Consequences

- Designed for **2–4 phones** (the use case). Works for more, but at 5+ tiles the experience moves from "ambient companions" to "wall of windows."
- Each tile shows a label so you can tell whose view is whose. Labels live in the same awareness state as frames.

## Alternatives considered

- **Hard-coded 2×2 grid.** Too rigid; breaks at 3 peers.
- **Drag-rearrange tile positions.** Out of scope for v1; the default sort is alphabetical-by-label which is stable enough.
- **Single big "hero" tile + thumbnails.** Better for video-call apps; this isn't one.
